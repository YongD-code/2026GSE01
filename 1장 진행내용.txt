0. CODEX 작업 원칙
======================================================================

이 문서는 소설용 시나리오가 아니라 게임 구현 기준 문서다.

구현 시 다음 요소를 서로 분리해서 관리한다.

1) STORY
- 챕터
- 퀘스트
- 대사
- 컷신
- 스토리 플래그

2) COMBAT
- 일반 몬스터
- 주령
- 엘리트
- 보스
- 공격 패턴
- 상태 이상

3) CAPTURE
- 포획 가능 상태
- 봉인권
- 포획 확률
- 포획 결과
- 주령 개체 변이
- 중복 주령 처리

4) PROGRESSION
- 경험치
- 장비
- 재료
- 강화
- 주령 슬롯
- 지역 해금

5) WORLD STATE
- NPC 상태
- 플레이어 선택
- 기억
- 관계
- 사건 결과
- 플레이어 사망 기록
- 전승 NPC

6) SAVE
- 획득 아이템
- 포획 주령
- 도감
- 퀘스트 진행
- 챕터
- 이벤트 플래그
- 플레이어 행동 기록

스토리 데이터와 전투 수치를 가능한 한 하드코딩하지 않는다.
몬스터, 주령, 아이템, 퀘스트, 대사, 드롭 테이블은 데이터 기반 구조를 우선한다.


======================================================================
1. 게임 핵심 콘셉트
======================================================================

장르:
- 2.5D RPG
- 주령 수집/포획
- 액션 전투
- 장비/재료 파밍
- 보스 사냥
- 지속적으로 확장되는 월드

배경:
- 중세 암흑시대
- 전쟁, 빈곤, 질병, 불신이 존재하는 세계
- 인간의 강한 감정과 사건에서 주령이 발생한다.

핵심 정서:
- 어둡고 불안한 세계
- 절망만 존재하지 않음
- 플레이어의 행동을 통해 작은 희망과 변화가 발생

주령:
- 단순 몬스터가 아니다.
- 장소의 역사, 인간의 감정, 반복된 사건과 연결된다.
- 적대/교섭/해방/포획 가능한 존재가 존재한다.
- 각 주령에는 기원과 기억이 존재할 수 있다.

중요:
주술회전의 고유 캐릭터, 기술명, 사건, 조직, 고유 설정을 복제하지 않는다.
참고하는 것은 "인간의 부정적 감정과 초자연적 존재", "주술적 전투", "점차 커지는 사건" 같은 추상적 구조다.


======================================================================
2. 게임의 핵심 플레이 루프
======================================================================

기본 루프:

탐험
→ 일반 몬스터/주령 발견
→ 전투
→ 아이템/재료/봉인권 파밍
→ 장비 강화
→ 주령 약화
→ 봉인권을 사용할지 결정
→ 주령 포획
→ 주령 조합/빌드 변경
→ 더 강한 지역 진입
→ 엘리트 전투
→ 지역 보스
→ 희귀 보상
→ 새로운 지역/스토리 해금

중요 설계:

[구버전 폐기]
"하루에 주령 한 마리만 포획"

[현재 기준]
"봉인권을 소비하여 주령 포획을 시도"

일반적인 주령 포획 횟수에 일일 1회 제한을 두지 않는다.

봉인권은:
- 퀘스트 보상
- 몬스터 드롭
- 엘리트 드롭
- 보스 보상
- 탐험
- 이벤트
등으로 획득 가능하다.


======================================================================
3. 포획 / 가챠 시스템
======================================================================

3.1 기본 규칙

주령 HP를 CaptureThreshold 이하로 낮추면 CAPTURABLE 상태가 될 수 있다.

예시:
CaptureThreshold = MaxHP * 0.20

단, 모든 주령이 포획 가능한 것은 아니다.

Spirit.captureAllowed = true / false


3.2 전투 종료 선택

주령이 CAPTURABLE 상태가 되면:

[A] 정화
- 주령 처치
- 일반 전투 보상 획득
- 포획권 소비 없음

[B] 포획
- 사용 가능한 봉인권 선택
- 봉인권 1개 소비
- 포획 판정 실행


3.3 봉인권 종류

ITEM_CAPTURE_OLD
표시명: 낡은 봉인권
용도: 하급/일반 주령
희귀 결과 보정: 낮음

ITEM_CAPTURE_NORMAL
표시명: 봉인권
용도: 일반적인 포획

ITEM_CAPTURE_HIGH
표시명: 고급 봉인권
용도: 강한 주령
희귀 결과 확률 상승

ITEM_CAPTURE_SPECIAL
표시명: 특급 봉인권
용도: 보스급/강대 주령

ITEM_CAPTURE_BOND
표시명: 인연의 봉인권
용도: 특정 사건/NPC/스토리와 연결된 특수 주령


3.4 가챠의 의미

가챠는 "메뉴에서 캐릭터를 무작위 소환"하는 구조를 기본으로 하지 않는다.

플레이어가 실제 필드에서:
- 주령을 발견하고
- 싸우고
- 약화시키고
- 봉인권을 사용했을 때
포획 결과에 랜덤성이 발생한다.

같은 종의 주령이라도 개체 차이가 존재할 수 있다.

예:
SpiritSpecies = SPIRIT_ABANDONED

Variant A:
남겨진 자 ★
Skill = 붙잡는 손

Variant B:
붉은 눈의 남겨진 자 ★★★
Skill = 붙잡는 손+
Passive = 버려진 분노

Variant C:
남겨진 자 / MemoryVariant
HiddenMemory = 돌아오지 않은 어머니


3.5 희귀도

초기 제안:

★
★★
★★★
★★★★
★★★★★

주의:
희귀도 = 절대 전투력으로 설계하지 않는다.

희귀도는 다음 요소에 영향을 줄 수 있다.

- 외형 변이
- 기억
- 특수 패시브
- 성장 방향
- 스킬 변형
- 도감 가치

낮은 희귀도 주령도 특정 빌드에서 강력할 수 있어야 한다.


3.6 임시 확률

첫 밸런스 테스트용 예시이며 확정 수치가 아니다.

일반 봉인권 예시:
★      70%
★★     25%
★★★     5%

보스는 별도의 CaptureChance를 사용한다.

첫 보스급 포획 테스트:
기도하지 않는 성자 = 20%

확률은 데이터 파일에서 변경 가능하게 구현한다.


3.7 실패 보호

포획 실패로 해당 콘텐츠가 영구 소실되어서는 안 된다.

보스 포획 실패 예:

기도하지 않는 성자 포획 실패
→ SPIRIT_REMAINS_SAINT 획득

일정 잔재를 모으면:
- 보스 재추적
- 재전투
- 특별 이벤트
중 하나를 통해 다시 포획할 기회를 제공할 수 있다.


3.8 중복 주령

같은 주령을 다시 포획할 수 있다.

중복 획득 시 플레이어 선택:

1. 기존 주령 성장 재료로 사용
2. 별도 개체로 보유

정확한 성장 수치는 추후 결정한다.

4. 전투 주령 슬롯
======================================================================

초기 목표:
전투 장착 주령 최대 3마리.

역할 예시:

ATTACK
공격형

DEFENSE
방어형

CONTROL
속박/제어형

HEAL
회복형

EXPLORE
탐색형

플레이어는 주령을 교체/소환하면서 본체와 함께 전투한다.

전투의 핵심은:
"주령이 대신 싸우는 게임"이 아니라
"플레이어 전투 + 주령 능력 조합"이다.

======================================================================
6. 전체 스토리 핵심 미스터리
======================================================================

게임 시작:
벨른 마을에서 사람들이 사라진다.

공동묘지에서 주령 사건 발생.

사건 해결 후:
마을 사람들이 실종자를 기억하지 못한다.

플레이어의 동생도 세계의 기억에서 사라진 것처럼 보인다.

플레이어와 라엔만 기억한다.

이후 발견:
검게 변한 성유물

문구:
"일곱 번째 종이 울리는 날, 문이 열린다."

후반부 진실:

세계 곳곳에는 인간의 거대한 감정이 축적된 장소들이 존재한다.

임시 분류:
- 전쟁
- 기아
- 질병
- 배신
- 신앙
- 사랑
- 죽음

각 장소는 강대한 주령과 연결된다.

임시 명칭:
칠흔(七痕)

주의:
"칠흔"은 현재 임시 이름이다.
코드 ID와 화면 표시명을 분리한다.

7. 핵심 등장인물
======================================================================

PLAYER
- 주인공
- 처음에는 주술사가 아니다.
- 주령을 보고 포획할 수 있는 특수한 능력을 발견한다.
- 행동/선택/전투 스타일이 LifeRecord에 축적된다.


NPC_RAEN
표시명: 라엔 (임시)

역할:
- 초반 안내자
- 주령에 대해 알고 있음
- 플레이어에게 최초 봉인을 가르침

중반 반전:
라엔은 평범한 인간이 아니다.

라엔은 과거 죽은 인간의:
- 성향
- 일부 기억
- 감정
을 계승해 탄생한 존재다.

라엔의 존재 자체가 플레이어 사망/전승 시스템의 복선이다.


NPC_ERN
표시명: 에른 (임시)

역할:
메인 빌런

목표:
세상을 파괴하려는 것이 아니다.

죽음을 없애려고 한다.

사상:
"죽음이 없다면 이별과 슬픔도 사라진다."

실제 계획:
인간의 기억과 감정을 하나의 거대한 의식에 연결한다.

결과:
죽음은 사라질 수 있지만 개인도 사라진다.


FACTION_STIGMA
표시명: 성흔회 (임시)

주령을 위험한 존재로 판단하는 종교적 조직.

주령을 사용하는 플레이어도 위험한 존재라고 판단한다.

완전한 악역 조직으로 만들지 않는다.

그들에게도 주령을 제거하려는 이유가 존재한다.

======================================================================
11. 엔딩
======================================================================

플레이어는 벨른 마을로 돌아온다.

이번에는 사람들이 플레이어를 기억한다.

과거에 도운 NPC들의 변화가 보인다.

플레이어는 낯선 NPC를 발견한다.

그 NPC는 CHAPTER 4에서 플레이어가 사망했을 때 생성된 전승 NPC.

NPC는 플레이어를 기억하지 못한다.

그러나:
- 플레이어가 자주 사용한 전투 방식
- 행동 습관
- 일부 성향
을 가지고 있다.

NPC는 플레이어 옆을 지나간다.

EndingText:

"죽음은 삶을 지우지 않는다."

"살아온 방식이 다음 세계를 만든다."


======================================================================
12. 엔딩 이후 게임
======================================================================

메인 스토리 종료 != 게임 종료.

POST_GAME 활성화.

Loop:

새로운 지역 탐험
→ 새로운 주령
→ 전투
→ 봉인권 파밍
→ 포획
→ 개체 가챠
→ 장비 파밍
→ 강화
→ 지역 보스
→ 보스 포획
→ 더 먼 지역

플레이어가 사망할 때마다:
LifeRecord 생성
→ InheritanceSystem
→ 새로운 NPC 생성
→ 월드에 등록

장기 목표:
플레이 시간이 길어질수록 각 플레이어의 월드에 서로 다른 NPC와 사건의 역사가 쌓인다.

======================================================================
17. 현재 미확정 사항
======================================================================

다음은 Codex가 임의로 확정하지 않는다.

- 최종 게임명
- 라엔 최종 이름
- 에른 최종 이름
- 성흔회 최종 이름
- 칠흔 최종 명칭
- 정확한 포획 확률
- 천장 시스템
- 유료 가챠/과금 여부
- 주령 최대 보유 수
- 중복 주령 성장 공식
- 플레이어 레벨 상한
- 장비 등급
- 정확한 전투 수치
- 최종 스킬 쿨다운
- 보스 재도전 방식
- 전투의 세부 조작 체계
- 사망 후 플레이어가 어떤 캐릭터로 재시작하는지
- 전승 NPC의 정확한 기억 계승 범위

임시값이 필요한 경우:
TEMP 또는 TODO로 명시하고 데이터화한다.
게임 규칙으로 영구 하드코딩하지 않는다.


======================================================================
18. 개발 시 유지해야 할 핵심 정체성
======================================================================

이 게임의 핵심은 단순한 몬스터 수집 게임이 아니다.

1.
주령에는 사연이 있다.

2.
주령을 발견하고 직접 싸운 뒤 포획한다.

3.
봉인권 때문에 포획할 대상을 선택해야 한다.

4.
포획 결과에는 가챠의 기대감이 있다.

5.
사냥과 파밍이 봉인권/장비/성장으로 연결된다.

6.
포획한 주령은 실제 전투 빌드에 사용된다.

7.
플레이어의 선택과 행동은 기록된다.

8.
죽음은 단순 GAME OVER가 아니다.

9.
죽은 플레이어의 삶은 새로운 NPC의 성향과 행동으로 남는다.

10.
메인 스토리 종료 후에도 세계와 주령 수집은 계속된다.

핵심 문장:

"탐험은 사건을 만들고,
수집은 기록을 남기며,
죽음은 새로운 생명으로 이어진다."
