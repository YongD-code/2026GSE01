마지막 불씨 — 1차 프로토타입
작성: 2026-09-08
게임명은 화면용 임시 이름입니다.

목표
어두운 중세 마을과 따뜻한 화톳불을 도형 기반 2.5D 장면으로 표현하고,
이동·대화·수집·조종의 기본 흐름을 직접 경험할 수 있게 합니다.

사용자 실행 안내
1. Visual Studio에서 SimpleGame.sln을 엽니다.
2. Debug / x64를 선택해 빌드하고 실행합니다.
3. 기본 창 크기는 1280×800입니다. UI는 이 크기를 기준으로 구성했습니다.
4. OpenGL 3.3 compatibility context를 지원하는 그래픽 환경이 필요합니다.
5. 실행 파일 옆에 freeglut.dll과 glew32.dll이 필요합니다.
   저장소의 x64/Debug 및 x64/Release 폴더에는 해당 런타임이 포함되어 있습니다.
외부 이미지나 셰이더 파일을 별도로 복사할 필요는 없습니다.
이 안내 작성 과정에서 빌드·실행·화면 확인은 수행하지 않았습니다.

조작
WASD / 방향키: 화면 방향으로 이동합니다.
Shift + 이동: 누르고 있는 동안 1.8배 속도로 달립니다. 놓으면 기본 속도로 돌아옵니다.
주령을 조종할 때도 Shift로 빠르게 이동할 수 있습니다.
E: 가장 가까운 대상과 상호작용합니다. 가까워지면 안내가 나타납니다.
Q: 포획한 주령과 플레이어 본체 사이에서 조종을 전환합니다.
J: 도감을 열고 닫습니다. 도감이 열리면 이동을 멈춥니다.
ESC: 도감 또는 대화 알림을 닫습니다.
창 닫기 버튼: 프로그램을 종료합니다.

권장 체험 순서
1. 중앙의 화톳불 주변으로 이동하여 마을의 공간과 건물 가림을 살펴봅니다.
2. 화톳불 근처의 작은 아이 미라에게 E로 말을 겁니다.
   장난감 칼을 받고, 다시 대화하면 선물을 기억하는 대사를 표시합니다.
3. 주변의 불씨지기 또는 화톳불과 상호작용합니다.
4. 시작 위치에서 화면 오른쪽으로 이동해 푸른 주령에게 접근합니다.
5. E로 포획한 뒤 J로 도감 기록을 엽니다.
6. 도감을 닫고 Q로 주령을 직접 조종합니다.
   본체는 그 자리에 남으며 Q를 다시 누르면 본체로 돌아옵니다.

이번에 작성한 기능
- 등각 투영으로 표현하는 작은 마을과 주변 황무지.
- 건물, 지붕, 창문, 마른 나무, 돌무더기와 지면 경로.
- 깊이에 따른 그리기 순서, 캐릭터 보행 표현, 추적 카메라.
- 지형 오브젝트와 월드 경계 충돌, 대각선 이동 속도 정규화.
- 불꽃, 주령의 부유, 빛 번짐, 낮은 안개와 날리는 재 표현.
- NPC 두 명과 화톳불의 상호작용.
- 장난감 칼 획득 여부를 반영하는 후속 대사와 도감 기록.
- 주령 한 개체의 포획·직접 조종·본체 복귀·동행 표시.
- 안내 메시지, 체력 표시, 수집 상태와 도감 창.
- 크기 변경 시 뷰포트 갱신, 프레임 시간 기반 이동, GPU 자원 해제.

프로토타입에서의 제한
- 월드는 작은 고정 지역입니다. 무한 청크 생성은 아직 구현하지 않았습니다.
- 대화는 직접 작성한 상태별 데모 대사입니다. AI 자동 생성은 아닙니다.
- 포획은 실행 세션당 한 번입니다. 실제 하루 제한과 저장은 아직 없습니다.
  화면에 체험 포획라고 명시했습니다. 재실행하면 모든 기록이 초기화됩니다.
- 체력 100은 UI 자리 표시입니다. 피해·전투·사망·전승 NPC는 미구현입니다.
- 장난감 칼은 획득과 대화 변화만 연결됩니다. 보스 효과는 미구현입니다.
- 주령 조종 중에도 같은 기본 충돌 규칙을 적용합니다. 고유 능력은 미구현입니다.
- 대사·도감·조작 안내는 한글이며, Windows 맑은 고딕을 사용합니다.
- 이미지 에셋과 음향을 사용하지 않습니다. 빛과 안개는 도형 기반 효과입니다.
- 작은 창에서는 긴 문구가 잘릴 수 있으므로 기본 크기를 권장합니다.

코드 구성
SimpleGame.cpp: OpenGL 초기화, 콜백, 프레임 시간, 종료 처리.
Renderer.h / Renderer.cpp: 화면 좌표 도형 배치, 셰이더와 버퍼, UTF-8 한글 텍스트.
Prototype.h: 데모 월드, 투영, 오브젝트, 조작, 상호작용과 UI.
기존 Shaders/SolidRect.vs 및 .fs는 보존되어 있지만 이번 렌더러에서는 사용하지 않습니다.
기존 DrawSolidRect 인터페이스는 배치 렌더링 함수로 유지되며 표시 전에 Flush가 필요합니다.

다음 단계
사용자가 빌드와 화면을 확인한 뒤 시점·색감·조작감부터 조정합니다.
이후 월드·캐릭터·UI 모듈 분리, 저장, 청크 확장과 전승 기록으로 진행합니다.
이번 변경은 로컬 파일에만 적용했습니다. 커밋과 push는 별도 요청 시 진행합니다.


후처리 추가 (dev)
- 장면을 GL_RGBA16F HDR 버퍼에 렌더링한 뒤 톤 매핑으로 화면에 출력합니다.
- 불꽃, 창문, 주령의 중심부에 1을 넘는 발광 색상을 적용했습니다.
- 밝은 영역 추출과 가로·세로 블러를 거친 블룸을 합성합니다.
- 화면 가장자리로 갈수록 비넷과 흐림이 점진적으로 강해집니다.
- UI와 한글 글자는 후처리 이후에 그려 선명하게 유지합니다.
- P: 후처리 전체 켜기/끄기. 기본값은 켜짐입니다.
- Renderer의 postProcess 설정으로 노출, 블룸 강도·임계값,
  비넷 강도, 가장자리 흐림 강도를 조정할 수 있습니다.
- 기본값: 노출 1.15 / 블룸 0.35 / 임계값 1.0 / 비넷 0.38 / 가장자리 흐림 0.65.
- 블러·블룸 버퍼는 가로·세로 절반 해상도를 사용합니다.
- 창 크기 변경 시 버퍼를 재생성하고 종료 시 GPU 자원을 해제합니다.
- 후처리 초기화 실패 시 기본 렌더링으로 돌아갑니다.
- HDR은 내부 고명암 렌더링이며, HDR10 디스플레이 출력 지원을 뜻하지 않습니다.
- 빌드·실행·화면 확인은 수행하지 않았습니다. P로 전후를 비교하며 조정해주세요.
