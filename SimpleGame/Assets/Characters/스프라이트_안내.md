# 캐릭터 스프라이트 사용 안내

## 현재 배치
- protagonist.png: 고죠 사토루 캐릭터.png → 조종하는 주인공.
- mira.png: NPC1.png → 기존 미라 위치(-100, 90).
- keeper.png: NPC2.png → 기존 불씨지기 위치(150, -100).
- 세 이미지 모두 사용자가 제공한 887×1774 투명 PNG 원본입니다.
- NPC는 원본 색상으로 표시하며 기존 대화와 상호작용을 유지합니다.

## 시트 규격과 방향
- 8행 × 4열. 각 행의 첫 열은 정지, 뒤의 3열은 걷기입니다.
- 위에서부터 아래 / 왼쪽 아래 / 왼쪽 / 왼쪽 위 / 위 / 오른쪽 위 / 오른쪽 / 오른쪽 아래.
- SpriteLayout의 rows=8, directionRows={0,1,2,3,4,5,6,7}을 세 캐릭터에 명시적으로 적용합니다.
- 주인공은 WASD/방향키 조합으로 8방향 이동하며 해당 방향의 이미지를 사용합니다.
- Shift 이동은 1.8배 속도이며 애니메이션 재생도 빨라집니다.
- NPC는 현재 고정 배치이며 플레이어가 가까이 오면 해당 방향을 바라봅니다.
- 이미지 자체의 방향별 구도 차이는 원본 그대로 유지합니다.

## 표시와 파일 배치
- 프레임의 투명 영역을 제외한 하단 중앙을 발 기준점으로 맞춥니다.
- 미라는 높이 55, 주인공과 불씨지기는 높이 78 기준으로 표시합니다.
- 프레임마다 확대 배율을 바꾸지 않으며 기존 충돌과 깊이 정렬을 사용합니다.
- PNG는 Windows WIC로 로드하고 기존 HDR 후처리 장면에 렌더링합니다.
- 빌드 시 Assets 아래 PNG를 실행 폴더의 Assets로 복사합니다.
- 이미지를 불러오지 못하면 콘솔에 알리고 임시 외형을 표시합니다.
- 새 NPC도 전용 SpriteSheet와 SpriteLayout을 지정해 같은 방식으로 배치합니다.
- 빌드·실행·렌더링 결과 확인은 수행하지 않았습니다.
