# 블렌더 주인공 에셋

기존 원화의 흰 머리, 안대, 검은 코트, 푸른 주술 문양을 참고한 **정교화한 절차적 3D 모델**입니다. 원본의 손그림 질감을 그대로 재현한 완성 모델은 아닙니다.

## 파일

- `protagonist.blend`: 편집 가능한 메시, 재질, 뼈대, 대기/걷기/달리기/주술 시전 액션, 직교 카메라.
- `create_protagonist.py`: Blender Python 제작·출력 원본. 재실행하면 이 스크립트의 모델로 blend와 출력 PNG를 덮어씁니다. 블렌더에서 직접 수정한 모델은 별도 이름으로 저장하세요.
- `../../SimpleGame/Assets/Characters/Blender/preview.png`: 모델 미리보기.
- 같은 폴더의 `walk.png`, `run.png`: 192×192 셀, 9열×8행. 첫 열 대기, 나머지 8열은 한 걸음 주기의 좌우 발 교대 동작.
- `cast.png`: 192×192 셀, 4열×8행 주술 시전.

방향 행 순서는 아래, 왼쪽 아래, 왼쪽, 왼쪽 위, 위, 오른쪽 위, 오른쪽, 오른쪽 아래입니다.

## 다시 제작하기

저장소 루트에서 PowerShell:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python Art/Blender/create_protagonist.py
```

미리보기만 만들려면 명령 뒤에 `-- --preview-only`를 붙입니다. Blender 기본 기능만 사용하며 추가 패키지는 필요하지 않습니다. Workbench 재질·조명을 사용한 투명 PNG 출력입니다.

## 게임 연결

새 걷기 시트가 있으면 주인공에 사용하고 Shift 이동 시 달리기 시트를 사용합니다. 기존 원화 PNG는 보존하며 새 시트가 없으면 기존 주인공으로 돌아갑니다. 시전도 새 모델의 8방향 시트를 사용합니다. MSBuild의 기존 Assets PNG 복사 규칙에 포함됩니다.

Blender 출력은 카메라와 바닥 기준점이 고정되어 있으므로 SpriteLayout의 fixedCanvas를 사용합니다. 기존 캐릭터의 자동 알파 크롭 방식은 그대로 유지합니다. 카메라 높이/직교 크기를 바꾸면 canvasAnchorY와 canvasCharacterHeight도 맞춰야 합니다.

## 범위와 확인

- Blender에서 모델/액션과 PNG를 생성하고 출력 이미지를 확인했습니다.
- 게임 빌드·실행·테스트는 수행하지 않았습니다.
- 걷기/달리기는 발목 목표 궤적으로부터 두 다리 관절 각도를 계산합니다. 지지 구간과 발을 들어 회수하는 구간을 구분합니다. 경사면 대응, 의상 물리, 손가락 개별 리깅, 손으로 그린 텍스처는 포함하지 않습니다. 게임 내 이동 속도와 보폭의 최종 조정은 플레이 확인이 필요합니다.
- 대기는 정지 포즈입니다. 주술 시전은 짧은 준비·발사 자세이며 게임의 기존 발사체 효과와 함께 사용합니다.

- 몸통·소매·바지를 링 단면 기반 연속 메시로 재제작하고, 팔꿈치·무릎 주변에 혼합 가중치를 적용했습니다.
- 얼굴에 턱선과 광대·이마 단면을 만들고 안대 봉제선, 귀, 손가락, 부츠 밑창·끈, 버클을 추가했습니다.

- 머리카락은 베지어 경로를 따르는 납작한 곡면 덩어리로 교체했습니다.
- 블렌더 파일에 천·피부·가죽·금속 재질 노드를 구성했습니다. 게임용 PNG 출력은 기존 Workbench 스튜디오 조명을 사용하며, 노드 기반 미세 표면과 거칠기 효과는 Eevee/Cycles에서 볼 수 있습니다.
- 기존 첫 모델과 제작 스크립트는 `initial_prototype`에 보관했습니다.
- 출력 규격·경로가 같아 게임의 기존 블렌더 에셋 연결을 그대로 사용합니다. 프리뷰는 768×768입니다.
